# Contributing

This repository is primarily a portfolio project, but clear bug reports and focused pull requests are welcome.

Before opening a pull request:

1. create a branch from `main`;
2. keep credentials and customer data out of commits;
3. run the relevant typecheck, tests and build;
4. explain the problem, the change and how it was verified.

For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
