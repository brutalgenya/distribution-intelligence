# Security Policy

## Supported version

Only the latest commit on `main` is maintained. This is a portfolio prototype and must not be treated as a production service without an independent security review.

## Reporting a vulnerability

Please do not publish sensitive findings in a public issue. Contact the repository owner through the portfolio contact details at [szkibadavid.com](https://szkibadavid.com) and include the affected area, reproduction steps and likely impact.

Do not include real credentials, personal data or customer data in reports.
